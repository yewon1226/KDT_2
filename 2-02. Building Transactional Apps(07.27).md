## 2. EML
### 1) READ
- Behavior Root(루트 엔티티)를 기준으로 RAP Business Object를 조회·생성·수정·삭제하는 ABAP 문법
```abap
" EML1 : 필요한 필드 조회
READ ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  FIELDS ( 필드명... )
  WITH CORRESPONDING #( 내부테이블 )
  RESULT DATA(결과).

" EML2 : 전체 필드 조회
READ ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  ALL FIELDS
  WITH CORRESPONDING #( 내부테이블 )
  RESULT DATA(결과).

" EML3 : 조회 + 오류/메시지
READ ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  ALL FIELDS
  WITH CORRESPONDING #( 내부테이블 MAPPING ... )
  RESULT 결과
  FAILED 실패
  REPORTED 메시지.

" EML4 : 조회 키 테이블을 직접 생성하여 조회
DATA 조회조건 TYPE TABLE FOR READ IMPORT <Behavior Root>.
조회조건 = VALUE #( ( 키필드 = 키값 ) ).

DATA 조회결과 TYPE TABLE FOR READ RESULT <Behavior Root>.
DATA 실패정보 TYPE RESPONSE FOR FAILED <Behavior Root>.

READ ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  ALL FIELDS
  WITH 조회조건
  RESULT 조회결과
  FAILED 실패정보.
```
```abap
CLASS zcl_a06_eml_read_01 DEFINITION
  PUBLIC
  FINAL
  CREATE PUBLIC .

  PUBLIC SECTION.
    INTERFACES if_oo_adt_classrun .
  PROTECTED SECTION.
  PRIVATE SECTION.
ENDCLASS.

CLASS zcl_a06_eml_read_01 IMPLEMENTATION.
  METHOD if_oo_adt_classrun~main.
    SELECT FROM zta06emp_D01
    FIELDS *
    WHERE skill_code = 'S02'
    INTO TABLE @DATA(lt_emp).

    "EML1
    " Behavior Root
    READ ENTITIES OF ZR_EMP_D1_A06
    ENTITY Employee
    FIELDS ( Pernr Ename SkillCode SkillText )
    WITH CORRESPONDING #( lt_emp )
    RESULT DATA(result_employees).

    " EML2
    READ ENTITIES OF ZR_EMP_D1_A06
    ENTITY Employee
    ALL FIELDS
    WITH CORRESPONDING #( lt_emp )
    RESULT DATA(result_employees).

    " EML3
    DATA lt_result TYPE TABLE FOR READ RESULT zr_emp_d1_a06.
    DATA ls_failed TYPE RESPONSE FOR FAILED zr_emp_d1_a06.

    READ ENTITIES OF zr_emp_d1_a06
    ENTITY Employee
    ALL FIELDS WITH CORRESPONDING #( lt_emp MAPPING Pernr = pernr )
    RESULT lt_result
    FAILED ls_failed
    REPORTED DATA(reported_employee).

    out->write( lt_result[ 1 ]-%key ).   " DB Key 출력
    out->write( lt_result[ 1 ]-%tky ).   " RAP Transaction Key 출력
    out->write( lt_result[ 1 ]-%pky ).   " Parent Key 출력

    " EML4
    DATA import_emps TYPE TABLE FOR READ IMPORT zr_emp_d1_a06.
    import_emps = value #( ( Pernr = '99999999' ) ).

    DATA result_emps TYPE TABLE FOR READ RESULT zr_emp_d1_a06.
*    DATA result_emp LIKE LINE OF result_emps.
    DATA failed_emp TYPE RESPONSE FOR FAILED zr_emp_d1_a06.

    READ ENTITIES OF zr_emp_d1_a06
    ENTITY Employee
    ALL FIELDS WITH import_emps
    RESULT result_emps
    FAILED failed_emp.

    out->write( result_emps ).
    out->write( failed_emp ).
  ENDMETHOD.
ENDCLASS.
```

### 2) CREATE
- EML Create는 %cid와 %control을 사용해 생성 데이터를 정의하고, COMMIT ENTITIES로 DB에 최종 저장
```abap
DATA <내부테이블> TYPE TABLE FOR CREATE <Behavior Root>.

<내부테이블> = VALUE #(
  (
    %cid = 'C1'                          " 생성 요청 ID
    필드 = 값
    %control-필드 = '01'                 " 01: 반영, 00: 미반영
    " 또는 if_abap_behv=>mk-on / mk-off
  )
).

MODIFY ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  CREATE FROM <내부테이블>
  MAPPED DATA(<성공>)                    " 성공
  FAILED DATA(<실패>)                    " 실패
  REPORTED DATA(<메시지>).               " 메시지

COMMIT ENTITIES RESPONSE OF <Behavior Root>
  FAILED DATA(<커밋실패>).               " Commit 실패
```
```abap

CLASS zcl_a06_eml_create_01 IMPLEMENTATION.
  METHOD if_oo_adt_classrun~main.
    DATA create_emps TYPE TABLE FOR CREATE zr_emp_d1_a06.

        (
            %cid = 'C1'
            Pernr = '40010005' %control-Pernr = '01'    " 00 - 적용 X, 01 - 적용

    COMMIT ENTITIES RESPONSE OF zr_emp_d1_a06
    FAILED DATA(failed_emp1).

    out->write( mapped_emps ).
    out->write( failed_emp ).
    out->write( reporte_emp ).
  ENDMETHOD.
```

### 3) UPDATE
- UPDATE1은 DB Key로 직접 수정하고, UPDATE2는 READ ENTITIES로 조회한 %tky(Transaction Key)를 이용해 더 안전하게 수정
```abap
" UPDATE1 : DB Key로 직접 수정
SELECT FROM <DB Table>
  FIELDS *
  WHERE 조건
  INTO TABLE @DATA(<내부테이블>).

MODIFY ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  UPDATE FIELDS ( 수정필드 )
  WITH VALUE #(
    FOR <wa> IN <내부테이블> (
      Key = <wa>-Key
      수정필드 = 값
    )
  )
  FAILED DATA(<실패>)
  REPORTED DATA(<메시지>).

COMMIT ENTITIES.

" UPDATE2 : READ 후 %tky로 수정
DATA <조회조건> TYPE TABLE FOR READ IMPORT <Behavior Root>.

SELECT FROM <DB Table>
  FIELDS Key
  WHERE 조건
  INTO TABLE @DATA(<내부테이블>).

MOVE-CORRESPONDING <내부테이블> TO <조회조건>.

READ ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  ALL FIELDS
  WITH <조회조건>
  RESULT DATA(<조회결과>).

MODIFY ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  UPDATE FIELDS ( 수정필드 )
  WITH VALUE #(
    FOR <wa> IN <조회결과> (
      %tky = <wa>-%tky
      수정필드 = 값
    )
  )
  FAILED DATA(<실패>)
  REPORTED DATA(<메시지>).

COMMIT ENTITIES.
```

```abap
CLASS zcl_a06_eml_update_01 DEFINITION
  PUBLIC
  FINAL
  CREATE PUBLIC .
  PUBLIC SECTION.
    INTERFACES if_oo_adt_classrun .
  PROTECTED SECTION.
  PRIVATE SECTION.

CLASS zcl_a06_eml_update_01 IMPLEMENTATION.
  METHOD if_oo_adt_classrun~main.
*    SELECT FROM zta06emp_d01
*        FIELDS *
*        WHERE skill_code = 'S02'
*        INTO TABLE @DATA(lt_emp).
*
*    LOOP AT lt_emp ASSIGNING FIELD-SYMBOL(<fs_emp>).
*      <fs_emp>-gesch = '1'.
*    ENDLOOP.
*
*    MODIFY ENTITIES OF zr_emp_d1_a06
*    ENTITY Employee
*    UPDATE FIELDS ( Gesch )
*    WITH VALUE #(
*        FOR  ls_emp IN lt_emp (
*            Pernr = ls_emp-pernr
*            Gesch = ls_emp-gesch
*        )
*    )
*    FAILED DATA(failed_data)
*    REPORTED DATA(reported_data).
*
*    COMMIT ENTITIES.
**********************************************************************
    DATA import_emps TYPE TABLE FOR READ IMPORT zr_emp_d1_a06.

    SELECT FROM zta06emp_d01
        FIELDS pernr
        WHERE skill_code = 'S02'
        INTO TABLE @DATA(lt_emp).

    MOVE-CORRESPONDING lt_emp TO import_emps.

    READ ENTITIES OF zr_emp_d1_a06
    ENTITY Employee
    ALL FIELDS WITH import_emps
    RESULT DATA(result_emps).

    MODIFY ENTITIES OF zr_emp_d1_a06
    ENTITY Employee
    UPDATE FIELDS ( Gesch )
    WITH VALUE #(
        FOR  emp IN result_emps (
            %tky = emp-%tky
            Gesch = '3'
        )
    )
    FAILED DATA(failed_data)
    REPORTED DATA(reported_data).

    COMMIT ENTITIES.
    out->write( result_emps ).
  ENDMETHOD.
ENDCLASS.
```

### 4) DELETE
```abap
" DELETE : 데이터 삭제
DATA <조회조건> TYPE TABLE FOR READ IMPORT <Behavior Root>.

SELECT FROM <DB Table>
  FIELDS Key
  WHERE 조건
  INTO TABLE @DATA(<내부테이블>).

MOVE-CORRESPONDING <내부테이블> TO <조회조건>.

READ ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  ALL FIELDS
  WITH <조회조건>
  RESULT DATA(<조회결과>).

DATA <삭제데이터> TYPE TABLE FOR DELETE <Behavior Root>.
<삭제데이터> = CORRESPONDING #( <조회결과> ).

MODIFY ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  DELETE FROM <삭제데이터>
  FAILED DATA(<실패>).

COMMIT ENTITIES.
```
```abap
CLASS zcl_a06_eml_delete_01 DEFINITION
  PUBLIC
  FINAL
  CREATE PUBLIC .
  PUBLIC SECTION.
    INTERFACES if_oo_adt_classrun .
  PROTECTED SECTION.
  PRIVATE SECTION.

CLASS zcl_a06_eml_delete_01 IMPLEMENTATION.
  METHOD if_oo_adt_classrun~main.
    DATA import_emps TYPE TABLE FOR READ IMPORT zr_emp_d1_a06.

    SELECT FROM zta06emp_d01
        FIELDS pernr
        WHERE skill_code = 'S01'
        INTO TABLE @DATA(lt_emp).

    MOVE-CORRESPONDING lt_emp TO import_emps.

    READ ENTITIES OF zr_emp_d1_a06
    ENTITY Employee
    ALL FIELDS WITH import_emps
    RESULT DATA(result_emps).

    DATA delete_emps TYPE TABLE FOR DELETE zr_emp_d1_a06.
    delete_emps = CORRESPONDING #( result_emps ).   " lt_emp 넣는거보다 좋음

    MODIFY ENTITIES OF zr_emp_d1_a06
    ENTITY Employee
    DELETE FROM delete_emps
    FAILED DATA(failed_data).

    COMMIT ENTITIES.
    out->write( delete_emps ).
    out->write( failed_data ).
  ENDMETHOD.
ENDCLASS.
```
