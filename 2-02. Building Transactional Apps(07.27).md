### 2) Interface View, Root View, Projection View 뷰 만들기
- ZI_GESCH_A06
```abap
@AbapCatalog.viewEnhancementCategory: [#NONE]
@AccessControl.authorizationCheck: #NOT_REQUIRED
@EndUserText.label: '[A06] 성별 Text { Domain Fixed Value }'
@Metadata.ignorePropagatedAnnotations: true
define view entity ZI_GESCH_A06
  as select from I_DomainFixedValueText
{
  key DomainValue as Gesch,
      DomainText as GeschText
}
where
      SAPDataDictionaryDomain = 'GESCH'
  and Language                = $session.system_language
```
- ZI_EMP_D1_A06
```abap
@AbapCatalog.viewEnhancementCategory: [#NONE]
@AccessControl.authorizationCheck: #NOT_REQUIRED
@EndUserText.label: '[A06] 사원 Base View'
@Metadata.ignorePropagatedAnnotations: true
define view entity ZI_EMP_D1_A06
  as select from zta06emp_d01
  association [0..1] to ZI_GESCH_A06 as _GeschInfo 
  on $projection.Gesch = _GeschInfo.Gesch
{
  key pernr           as Pernr,
      ename           as Ename,
      gesch           as Gesch,
      skill_code      as SkillCode,
      created_by      as CreatedBy,
      creation_at     as CreationAt,
      last_changed_by as LastChangedBy,
      last_changed_at as LastChangedAt,
      _GeschInfo
}
```
- ZR_EMP_D1_A06
```abap
@AccessControl.authorizationCheck: #NOT_REQUIRED
@EndUserText.label: '[A06] 사원 Root View'
@Metadata.ignorePropagatedAnnotations: true // true로 냅두는거 추천
define root view entity ZR_EMP_D1_A06
  as select from ZI_EMP_D1_A06
  association [0..*] to I_DomainFixedValueText as _SkillInfo on  $projection.SkillCode              = _SkillInfo.DomainValue
                                                             and _SkillInfo.SAPDataDictionaryDomain = 'ZDSKILL_A06'
{
  key Pernr,
      Ename,
      Gesch,
      SkillCode,
      @Semantics.user.createdBy: true
      CreatedBy,
      @Semantics.systemDateTime.createdAt: true
      CreationAt,
      @Semantics.user.lastChangedBy: true
      LastChangedBy,
      @Semantics.systemDateTime.lastChangedAt: true
      LastChangedAt,
      _SkillInfo[ 1:Language = $session.system_language ].DomainText as SkillText,
      _GeschInfo
}
```

## 2. EML
- Behavior Root(루트 엔티티)를 기준으로 RAP Business Object를 조회·생성·수정·삭제하는 ABAP 문법
```abap
" EML1 : 필요한 필드 조회
READ ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  FIELDS ( 필드명... )
  WITH CORRESPONDING #( 내부테이블 )
  RESULT DATA(결과).

" EML2 : 전체 필드 조회
READ ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  ALL FIELDS
  WITH CORRESPONDING #( 내부테이블 )
  RESULT DATA(결과).

" EML3 : 조회 + 오류/메시지
READ ENTITIES OF <Behavior Root>
  ENTITY <Entity>
  ALL FIELDS
  WITH CORRESPONDING #( 내부테이블 MAPPING ... )
  RESULT 결과
  FAILED 실패
  REPORTED 메시지.
```
```abap
CLASS zcl_a06_eml_read_01 DEFINITION
  PUBLIC
  FINAL
  CREATE PUBLIC .

  PUBLIC SECTION.
    INTERFACES if_oo_adt_classrun .
  PROTECTED SECTION.
  PRIVATE SECTION.
ENDCLASS.

CLASS zcl_a06_eml_read_01 IMPLEMENTATION.
  METHOD if_oo_adt_classrun~main.
    SELECT FROM zta06emp_D01
    FIELDS *
    WHERE skill_code = 'S02'
    INTO TABLE @DATA(lt_emp).

    "EML1
    " Behavior Root
    READ ENTITIES OF ZR_EMP_D1_A06
    ENTITY Employee
    FIELDS ( Pernr Ename SkillCode SkillText )
    WITH CORRESPONDING #( lt_emp )
    RESULT DATA(result_employees).

    " EML2
    READ ENTITIES OF ZR_EMP_D1_A06
    ENTITY Employee
    ALL FIELDS
    WITH CORRESPONDING #( lt_emp )
    RESULT DATA(result_employees).

    " EML3
    DATA lt_result TYPE TABLE FOR READ RESULT zr_emp_d1_a06.
    DATA ls_failed TYPE RESPONSE FOR FAILED zr_emp_d1_a06.

    READ ENTITIES OF zr_emp_d1_a06
    ENTITY Employee
    ALL FIELDS WITH CORRESPONDING #( lt_emp MAPPING Pernr = pernr )
    RESULT lt_result
    FAILED ls_failed
    REPORTED DATA(reported_employee).

    out->write( lt_result[ 1 ]-%key ).   " DB Key 출력
    out->write( lt_result[ 1 ]-%tky ).   " RAP Transaction Key 출력
    out->write( lt_result[ 1 ]-%pky ).   " Parent Key 출력
  ENDMETHOD.
ENDCLASS.
```
