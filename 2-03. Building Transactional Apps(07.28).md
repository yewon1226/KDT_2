### 2) Behavior 루트뷰, 프로젝션뷰
- Action을 정의하고, 실행 결과로 현재 Entity($self)를 최대 1건 반환
```abap
action <Action명> result[0..1] $self;
```
- ZR_EMP_D1_A06
```abap
managed implementation in class zbp_r_emp_d1_a06 unique;
strict ( 2 );

define behavior for ZR_EMP_D1_A06 alias Employee
persistent table zta06emp_d01
lock master
authorization master ( instance )
etag master LastChangedAt
{
  create;
  update;
  delete;
  field ( mandatory : create ) Pernr;
  field ( readonly ) PernrStop, SkillText;

  action set_stop_pernr result[0..1] $self;

  // corresponding 쓰면 대소문자 구분 안함.
  // 그래도 써주는걸 추천
  mapping for zta06emp_d01 corresponding
    {
      //      Pernr         = pernr;
      //      Ename         = ename;
      //      Gesch         = gesch;
      SkillCode     = skill_code;
      PernrStop     = pernr_stop;
      CreationAt    = creation_at;
      CreatedBy     = created_by;
      LastChangedAt = last_changed_at;
      LastChangedBy = last_changed_by;
    }
}
```

### 3) Class 구현
- Action 실행 후 변경된 데이터를 현재 화면에 즉시 갱신하기 위해 `%tky`와 `%param`으로 결과를 반환
```abap
result = VALUE #(
  FOR <Entity> IN <조회결과> (
    %tky   = <Entity>-%tky
    %param = <Entity>
  )
).
```
- action set_stop_pernr
- `IN LOCAL MODE` : readonly 등 일반적으로 수정할 수 없는 필드를 Behavior 내부에서 수정할 때 사용
```abap
CLASS lhc_Employee DEFINITION INHERITING FROM cl_abap_behavior_handler.
  PRIVATE SECTION.
    METHODS get_instance_authorizations FOR INSTANCE AUTHORIZATION
      IMPORTING keys REQUEST requested_authorizations FOR Employee RESULT result.
    METHODS set_stop_pernr FOR MODIFY
      IMPORTING keys FOR ACTION employee~set_stop_pernr RESULT result.
ENDCLASS.

CLASS lhc_Employee IMPLEMENTATION.
  METHOD get_instance_authorizations.
  ENDMETHOD.

  METHOD set_stop_pernr.
    " PernrStop Update : 'X'
    MODIFY ENTITIES OF zr_emp_d1_a06 IN LOCAL MODE      " PernrStop가 ReadOnly이므로
        ENTITY Employee                                 " IN LOCAL MODE 를 쓰지 않으면 에러
        UPDATE FIELDS ( PernrStop )
        WITH VALUE #(
            FOR key IN keys (
                %tky = key-%tky
                PernrStop = 'X'
            )
        )
        FAILED DATA(ls_failed)
        REPORTED DATA(reported_emp).

    READ ENTITIES OF zr_emp_d1_a06 IN LOCAL MODE
        ENTITY Employee
        ALL FIELDS WITH CORRESPONDING #( keys )
        RESULT DATA(result_emps).

    result = VALUE #(
        FOR emp IN result_emps (
            %tky = emp-%tky
            %param = emp
        )
    ).

**********************************************************************

    READ ENTITIES OF zr_emp_d1_a06 IN LOCAL MODE
        ENTITY Employee
        ALL FIELDS WITH CORRESPONDING #( keys )
        RESULT DATA(temp_emps).

    DATA update_emps TYPE TABLE FOR UPDATE zr_emp_d1_a06.

    update_emps = VALUE #(
        FOR emp IN temp_emps
        WHERE ( PernrStop <> 'X' ) (
            %tky = emp-%tky
            PernrStop = 'X'
            %control-PernrStop = if_abap_behv=>mk-on
        )
    ).

    IF update_emps IS NOT INITIAL.
      MODIFY ENTITIES OF zr_emp_d1_a06 IN LOCAL MODE
          ENTITY Employee
          UPDATE FROM update_emps
          FAILED DATA(failed_emp)
          REPORTED DATA(reported_emp).
    ENDIF.

    READ ENTITIES OF zr_emp_d1_a06 IN LOCAL MODE
        ENTITY Employee
        ALL FIELDS WITH CORRESPONDING #( keys )
        RESULT DATA(result_emps).

    result = VALUE #(
        FOR emp IN result_emps (
            %tky = emp-%tky
            %param = emp
        )
    ).
  ENDMETHOD.
ENDCLASS.
```

## 2. RAP Behavior - Action 메시지 출력

```abap
MODIFY ENTITIES OF <Behavior Root> IN LOCAL MODE
  ENTITY <Entity>
  UPDATE FIELDS ( <수정필드> )
  WITH VALUE #(
    FOR key IN keys (
      %tky       = key-%tky
      <수정필드> = <수정값>
    )
  )
  FAILED DATA(<실패>)
  REPORTED DATA(<메시지>).

IF <실패> IS INITIAL.
  MESSAGE s<번호>(<메시지클래스>)
    WITH <변수1> <변수2>
    INTO DATA(<메시지텍스트>).          " 메시지 생성

  DATA(<대상>) = VALUE #( keys[ 1 ] ).  " 첫 번째 대상

  APPEND VALUE #(
    %tky = <대상>-%tky
    %msg = new_message(
      id       = '<메시지클래스>'      " 메시지 클래스
      number   = '<메시지번호>'        " 메시지 번호
      v1       = <메시지텍스트>        " 메시지 변수
      severity = if_abap_behv_message=>severity-information  " 정보/경고/오류
    )
  ) TO reported-<Entity>.              " UI 출력

  failed-<Entity> = VALUE #(
    ( %tky = <대상>-%tky )
  ).                                   " 실패 처리
  RETURN.
ENDIF.
```
