### 1) Search Annotation (검색 설정)
- 검색 기능을 활성화하고 검색 대상 필드를 지정
```abap
@Search.searchable: true
<CDS View>

@Search.defaultSearchElement: true
<검색필드>

@Search: {
    defaultSearchElement: true,
    fuzzinessThreshold: 0.8
}
<검색필드>
```
- ZC_EMP_D2_A06 (프로젝션뷰)
```abap
@AccessControl.authorizationCheck: #NOT_REQUIRED
@EndUserText.label: '[A06] 사원 Projection View'
@Metadata.ignorePropagatedAnnotations: true
@Metadata.allowExtensions: true
@Search.searchable: true
define root view entity ZC_EMP_D2_A06 
provider contract transactional_query
as projection on ZR_EMP_D2_A06
{
    key Pernr,
    @Search: { 
        defaultSearchElement: true,
        fuzzinessThreshold: 0.8
    }
    Ename,
    @ObjectModel.text.element: [ 'GeschText' ]
    @Consumption.valueHelpDefinition: [
        {  
            entity: { name: 'ZI_GESCH_A06', element: 'Gesch' }
        }
    ]
    Gesch,
    @Search.defaultSearchElement: true
    SkillCode,
    PernrStop,
    Begda,
    @Semantics.amount.currencyCode: 'Waers'
    Price,
    Waers,
    CreatedBy,
    CreationAt,
    LastChangedBy,
    LastChangedAt,
    _GeschInfo.GeschText as GeschText,       // 조회모드
    SkillText
}
```
