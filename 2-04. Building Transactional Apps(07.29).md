### 2) Determination (기본값 설정)
- 사용자가 생성(Create) 화면에서 데이터를 입력하고 저장(Save)하는 순간, 시스템이 자동으로 기본값을 넣어
```abap
" Behavior Definition Root
determination <메서드명> on save {
    <create / update>;    " 실행 시점
    field <필드>;          " 해당 필드 변경 시 실행
}

" Class
METHODS <메서드명>        " Behavior Handler
  FOR DETERMINE ON SAVE
  IMPORTING keys FOR <Entity>~<메서드명>.

METHOD <메서드명>.        " Implementation
  MODIFY ENTITIES OF <Behavior Root> IN LOCAL MODE
    ENTITY <Entity>
    UPDATE FIELDS ( <필드> )
    WITH VALUE #(
      (
        %tky = <키>
        <필드> = <기본값>
      )
    ).
ENDMETHOD.
```

```abap
managed implementation in class zbp_r_emp_d2_a06 unique;

    }
}
```

- set_dafault (클래스)
```abap
CLASS lhc_Employee DEFINITION INHERITING FROM cl_abap_behavior_handler.
  PRIVATE SECTION.
    METHODS get_instance_authorizations FOR INSTANCE AUTHORIZATION
      IMPORTING keys REQUEST requested_authorizations FOR Employee RESULT result.
    METHODS set_dafault FOR DETERMINE ON SAVE
      IMPORTING keys FOR employee~set_dafault.
    METHODS set_default_begda FOR DETERMINE ON SAVE
      IMPORTING keys FOR employee~set_default_begda.
ENDCLASS.

CLASS lhc_Employee IMPLEMENTATION.
  METHOD get_instance_authorizations.
  ENDMETHOD.

  METHOD set_dafault.
    DATA(ls_key) = VALUE #( keys[ 1 ] ).
    MODIFY ENTITIES OF zr_emp_d2_a06 IN LOCAL MODE
        ENTITY Employee
        UPDATE FIELDS ( Waers )
        WITH VALUE #( ( %tky = ls_key-%tky
                        Waers = 'KRW') ) " 인터널 테이블 형태
        FAILED DATA(failed).
  ENDMETHOD.

  METHOD set_default_Begda.
    MODIFY ENTITIES OF zr_emp_d2_a06 IN LOCAL MODE
        ENTITY Employee
        UPDATE FIELDS ( Begda )
        WITH VALUE #(
            FOR key IN keys (
                %tky = key-%tky
                Begda = cl_abap_context_info=>get_system_date(  )
            )
        )
        FAILED DATA(ls_failed).
  ENDMETHOD.
ENDCLASS.
```
