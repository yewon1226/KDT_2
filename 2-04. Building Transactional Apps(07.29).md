### 2) Determination (기본값 설정)
- 사용자가 생성(Create) 화면에서 데이터를 입력하고 저장(Save)하는 순간, 시스템이 자동으로 기본값을 넣어
```abap
" Behavior Definition Root
determination <메서드명> on save {
    <create / update>;    " 실행 시점
    field <필드>;          " 해당 필드 변경 시 실행
}

" Class
METHODS <메서드명>        " Behavior Handler
  FOR DETERMINE ON SAVE
  IMPORTING keys FOR <Entity>~<메서드명>.

METHOD <메서드명>.        " Implementation
  MODIFY ENTITIES OF <Behavior Root> IN LOCAL MODE
    ENTITY <Entity>
    UPDATE FIELDS ( <필드> )
    WITH VALUE #(
      (
        %tky = <키>
        <필드> = <기본값>
      )
    ).
ENDMETHOD.
```

### 3) Validation (데이터 검증)
- 저장(Create/Update) 시 데이터의 유효성을 검사하고, 조건에 맞지 않으면 저장을 막음
- 저장 시 `Determination → Validation → DB` 저장 순으로 실행
```abap
" Behavior Definition Root
validation <메서드명> on save { <create / update>; }

" Class
METHODS <메서드명>        " Behavior Handler
  FOR VALIDATE ON SAVE
  IMPORTING keys FOR <Entity>~<메서드명>.

" Implementation
METHOD <메서드명>.
  READ ENTITIES OF <Behavior Root>
    ENTITY <Entity>
    ALL FIELDS
    WITH CORRESPONDING #( keys )
    RESULT DATA(<조회결과>).

  " 데이터 검증
  IF <조건>.
    APPEND VALUE #(
      %tky = <조회결과>-%tky
      %msg = new_message(
                id       = '<메시지클래스>'
                number   = '<번호>'
                severity = if_abap_behv_message=>severity-error )
    ) TO reported-<Entity>.

    APPEND VALUE #(
      %tky = <조회결과>-%tky
    ) TO failed-<Entity>.
  ENDIF.
ENDMETHOD.
```
