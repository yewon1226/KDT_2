## 1) Draft Action (초안 기능)
- 생성·수정·삭제 내용을 임시 저장한 뒤, Activate 시 실제 DB에 반영하기 위한 기능
```abap
" Behavior Definition Root
with draft;                                 " Draft 기능 활성화
draft table <Draft_Table>;                  " Draft(임시 저장) 테이블 지정

draft action Edit;                          " 기존 데이터를 Draft로 복사하여 편집
draft action Activate optimized;            " Draft를 실제 DB에 저장
draft action Discard;                       " Draft 삭제(편집 취소)
draft action Resume;                        " 저장된 Draft 이어서 편집
draft determine action Prepare;             " 저장 전 Validation/Determination 수행

" Projection Behavior
use draft;                                  " Projection에서 Draft 사용

use action Edit;                            " Edit Action 사용
use action Activate;                        " Activate Action 사용
use action Discard;                         " Discard Action 사용
use action Resume;                          " Resume Action 사용
use action Prepare;                         " Prepare Action 사용
```

## 2) Draft 기본값 및 필드 제어
- Draft 생성 시 기본값을 설정하거나, Draft 상태에 따라 필드 속성을 제어하는 기능
```abap
" Behavior Definition Root
determination <메서드명> on modify { create; }  " 새 Draft 생성 시 1회 실행

" Class
" Implementation - 기본값 설정
METHOD <메서드명>.
  MODIFY ENTITIES OF <Behavior_Root> IN LOCAL MODE
    ENTITY <Entity>
    UPDATE FIELDS ( <Field1> <Field2> )
    WITH VALUE #(
      FOR key IN keys (
        %tky     = key-%tky
        <Field1> = <Value1>
        <Field2> = <Value2>
      )
    ).
ENDMETHOD.

" Implementation - Draft 상태 필드 제어
METHOD get_instance_features.
  IF keys[ 1 ]-%is_draft = if_abap_behv=>mk-on.    " on이면 true, off면 false
    <Result>-%tky = keys[ 1 ]-%tky.
    <Result>-%features-%field-<Field>
      = if_abap_behv=>fc-f-read_only.
    APPEND <Result> TO result.
  ENDIF.
ENDMETHOD.
```
- ZR_SKILL_A06 (Behavior 루트)
```abap
managed implementation in class zbp_r_skill_a06 unique;
strict ( 2 );
with draft;

define behavior for ZR_SKILL_A06 alias Skill
persistent table zta06skill
draft table zta06skilld

authorization master ( instance )
etag master LastChangedAt
{
  create;
  update;
  delete;

  field ( numbering : managed, readonly ) SkillUuid;
  field ( mandatory : create ) SkillCode;
  field ( readonly ) MaxExtraPrice;
  field( features : instance ) Waers;

  // 드래프트 버전을 처음 만들때만 실행
  determination set_default_value on modify { create; }

  draft action Edit;
  draft action Activate optimized;
  draft action Discard;
  draft action Resume;
  draft determine action Prepare;

  mapping for zta06skill corresponding
    {
      SkillUuid     = skill_uuid;
      SkillCode     = skill_code;
      SkillText     = skill_text;
      MaxExtraPrice = max_extra_price;
      ExtraPrice    = extra_price;
      CreatedBy     = created_by;
      CreationAt    = creation_at;
      LastChangedBy = last_changed_by;
      LastChangedAt = last_changed_at;
    }
}
```

- zbp_r_skill_a06 (클래스)
```abap
CLASS lhc_Skill DEFINITION INHERITING FROM cl_abap_behavior_handler.
  PRIVATE SECTION.
    METHODS get_instance_authorizations FOR INSTANCE AUTHORIZATION
      IMPORTING keys REQUEST requested_authorizations FOR Skill RESULT result.
    METHODS set_default_value FOR DETERMINE ON MODIFY
      IMPORTING keys FOR skill~set_default_value.
    METHODS get_instance_features FOR INSTANCE FEATURES
      IMPORTING keys REQUEST requested_features FOR skill RESULT result.
ENDCLASS.

CLASS lhc_Skill IMPLEMENTATION.
  METHOD get_instance_authorizations.
  ENDMETHOD.

  METHOD get_instance_features.
    DATA ls_result LIKE LINE OF result.

    if keys[ 1 ]-%is_draft = if_abap_behv=>mk-on.   " 드래프트 버전이라면 on - true
        ls_result-%tky = keys[ 1 ]-%tky.
*        ls_result-%field-Waers = if_abap_behv=>fc-f-read_only. " 아래의 단축. 아래가 정확.
        ls_result-%features-%field-Waers = if_abap_behv=>fc-f-read_only.
        APPEND ls_result TO result.
    ENDIF.
  ENDMETHOD.

  METHOD set_default_value.
    MODIFY ENTITIES OF ZR_SKILL_A06 IN LOCAL MODE
        ENTITY Skill
        UPDATE FIELDS ( Waers ExtraPrice )
        WITH VALUE #(
            FOR key IN keys (
                %tky = key-%tky
                Waers = 'KRW'
                ExtraPrice = 1000 " 뒤 .00을 생각하기
            )
        ).
  ENDMETHOD.
ENDCLASS.
```
