### 2) 부모 Root 뷰 생성
- ZR_A06_SKILL

- ZR_A06_SKILL
- `composition [0..*]` : 부모 Root View에서 자식 View를 연결
```abap
@AccessControl.authorizationCheck: #NOT_REQUIRED
@EndUserText.label: '[A06] 기술(부모) Root View'
@Metadata.ignorePropagatedAnnotations: true
define root view entity ZR_A06_SKILL as select from zta06skill_d03
composition [0..*] of ZI_A06_SKILL_TEXT as _ChildText
{
    key skill_uuid as SkillUuid,
    skill_code as SkillCode,
    @Semantics.amount.currencyCode: 'Waers'
    max_extra_price as MaxExtraPrice,
    @Semantics.amount.currencyCode: 'Waers'
    extra_price as ExtraPrice,
    waers as Waers,
    @Semantics.user.createdBy: true
    created_by as CreatedBy,
    @Semantics.systemDateTime.createdAt: true
    creation_at as CreationAt,
    @Semantics.user.lastChangedBy: true
    last_changed_by as LastChangedBy,
    @Semantics.systemDate.lastChangedAt: true
    last_changed_at as LastChangedAt,
    @Semantics.systemDate.localInstanceLastChangedAt: true
    local_last_changed_at as LocalLastChangedAt,
    _ChildText
}
```

### 3) 자식 Interface 뷰 생성 

<img width="504" height="316" alt="image" src="https://github.com/user-attachments/assets/1536f584-094c-47ac-8a4f-35ab46573d4f" />

- ZI_A06_SKILL_TEXT
- `association to parent` : 자식(Child View)에서 부모(Root View)를 연결하기 위해 사용
```abap
@AbapCatalog.viewEnhancementCategory: [#NONE]
@AccessControl.authorizationCheck: #NOT_REQUIRED
@EndUserText.label: '[A06] 기술명 Interface View'
@Metadata.ignorePropagatedAnnotations: true
define view entity ZI_A06_SKILL_TEXT as select from zta06skill_d03_t
association to parent ZR_A06_SKILL as _SkillHeader
    on $projection.SkillUuid = _SkillHeader.SkillUuid
{
    key skill_uuid as SkillUuid,
    key langu as Langu,
    skill_text as SkillText,
    _SkillHeader
}
```

### 4) 부모-자식 Projection 뷰 생성
- ZC_A06_SKILL (부모)
- `redirected to composition child` : Root View의 자식 연결을 Projection View의 자식으로 재연결하기 위해 사용
```abap
@AccessControl.authorizationCheck: #NOT_REQUIRED
@EndUserText.label: '[A06] 기술(부모) Projection View'
@Metadata.ignorePropagatedAnnotations: true
@Metadata.allowExtensions: true
define root view entity ZC_A06_SKILL 

as projection on ZR_A06_SKILL
{
    key SkillUuid,
    SkillCode,
    @Semantics.amount.currencyCode: 'Waers'
    MaxExtraPrice,
    @Semantics.amount.currencyCode: 'Waers'
    ExtraPrice,
    Waers,
    CreatedBy,
    CreationAt,
    LastChangedBy,
    LastChangedAt,
    LocalLastChangedAt,
    /* Associations */
    _ChildText : redirected to composition child ZC_A06_SKILL_TEXT
}
```
- ZC_A06_SKILL_TEXT (자식)
- `redirected to parent` : 자식 Projection View에서 부모 Projection View를 연결하기 위해 사용
```abap
@AccessControl.authorizationCheck: #NOT_REQUIRED
@EndUserText.label: '[A06] 기술명(자식) Projection View'
@Metadata.ignorePropagatedAnnotations: true
@Metadata.allowExtensions: true
define view entity ZC_A06_SKILL_TEXT 
as projection on ZI_A06_SKILL_TEXT
{
    key SkillUuid,
    key Langu,
    SkillText,
    /* Associations */
    _SkillHeader : redirected to parent ZC_A06_SKILL
}
```

```abap

persistent table zta06skill_d03
draft table zta06skill_d03d     // 4번째
lock master total etag LastChangedAt    // 1번째
authorization master ( instance )
etag master LocalLastChangedAt      // 1번째
{
  create;
  update;
  delete;
  association _ChildText { create; with draft; }    // 5번째
```
